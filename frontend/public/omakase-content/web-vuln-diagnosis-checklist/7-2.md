# 7-2. 파일 목록화 가능성

> 웹 서버의 디렉터리 인덱싱 기능이 활성화되어 있을 때,  
> 해당 디렉터리의 모든 파일 목록이 노출되어 서버 구조 및 주요 설정 파일이 유출될 수 있는 취약점.

---

## 근본적인 원인

- 웹 서버의 디렉터리 인덱싱 옵션이 기본값(활성화)으로 방치
- 디렉터리에 `index.html`, `index.jsp` 등 기본 인덱스 파일 없을 때 파일 목록 출력
- Apache `Options Indexes`, Tomcat `listings=true`, WebLogic `index-directory-enabled=true` 등 미변경

---

## 2차 피해 시나리오

- 백업 파일, 설정 파일, 소스코드 파일 경로 노출 → 직접 다운로드
- 웹 서버 디렉터리 구조 파악 → 취약한 파일 탐색 고도화
- WEB-INF, 설정 파일 경로 노출 → DB 접속 정보, 비밀키 탈취

---

## 해결 및 대응방안

### ① Apache: Indexes 옵션 제거

```apache
# httpd.conf: Options에서 "Indexes" 제거
<Directory "/usr/local/apache/htdocs">
    # 수정 전: Options Indexes FollowSymLinks MultiViews
    # 수정 후:
    Options FollowSymLinks MultiViews
    # Indexes 제거 → index 파일 없을 때 403 Forbidden 반환
</Directory>

# 스크립트 실행 방지 추가 옵션
# IncludesNoExec: 스크립트나 프로그램 실행 차단
```

### ② Tomcat: DefaultServlet listings 비활성화

```xml
<!-- [Tomcat 설치 디렉터리]/conf/web.xml -->
<servlet>
  <servlet-name>default</servlet-name>
  <servlet-class>org.apache.catalina.servlets.DefaultServlet</servlet-class>
  <init-param>
    <param-name>debug</param-name>
    <param-value>0</param-value>
  </init-param>
  <init-param>
    <param-name>listings</param-name>
    <!-- 수정 전: true -->
    <param-value>false</param-value>
  </init-param>
  <load-on-startup>1</load-on-startup>
</servlet>
```

### ③ WebLogic: 디렉터리 인덱싱 비활성화

```xml
<!-- weblogic.xml -->
<container-descriptor>
  <!-- 수정 전: <index-directory-enabled>true</index-directory-enabled> -->
  <index-directory-enabled>false</index-directory-enabled>
</container-descriptor>
```

### ④ Resin: directory-servlet 비활성화

```xml
<!-- resin.conf -->
<web-app id='/'>
  <!-- 수정 전: <directory-servlet id='false'/> -->
  <directory-servlet id='none'/>
</web-app>
```

### ⑤ IIS 5.x/6.x: 디렉터리 검색 체크 해제

```
IIS 5.x/6.x:
  설정 → 제어판 → 인터넷 정보 서비스 관리자
  → [해당 웹사이트] → [속성] → [홈 디렉터리] 탭
  → "디렉터리 검색" 체크 해제

IIS 7.x 이상:
  IIS 관리자 → [해당 웹사이트] → IIS → [디렉터리 검색]
  → "사용 안 함" 설정
```

### ⑥ Nginx: autoindex 비활성화

```nginx
server {
    location / {
        autoindex off;  # 기본값 off, 명시적 확인
    }
}
```

### ⑦ JBoss: listings=false 설정

```xml
<!-- ${JBOSS_HOME}/server/default/deploy/jbossweb-tomcat50.sar/conf/web.xml -->
<servlet>
  <servlet-name>default</servlet-name>
  <servlet-class>org.apache.catalina.servlets.DefaultServlet</servlet-class>
  <init-param>
    <param-name>listings</param-name>
    <param-value>false</param-value>
  </init-param>
</servlet>
```

---

## 보완방안

- 모든 디렉터리에 기본 index 파일(`index.html`, `index.jsp`) 배치하여 폴백으로 빈 페이지 반환
- 민감 디렉터리(`WEB-INF`, `META-INF`, 업로드 폴더)는 웹 루트 외부로 이동
- 설정 변경 후 서비스 영향도 확인 — 정적 파일 서빙 구조에 따라 영향 가능
