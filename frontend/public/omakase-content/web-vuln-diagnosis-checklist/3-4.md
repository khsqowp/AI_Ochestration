# 3-4. 관리자 페이지 분리 여부

> 일반 사용자와 관리자 로그인 페이지가 동일하거나 관리자 페이지가 외부에서 접근 가능한 경우,  
> 공격자가 관리자 인터페이스에 직접 접근·공격을 시도할 수 있는 취약점.

---

## 근본적인 원인

- 일반 사용자 서비스와 관리자 서비스가 동일 서버·동일 포트에서 운영
- 관리자 페이지 경로에 `admin`, `master`, `manager` 등 추측 가능한 단어 사용
- 관리자 페이지에 추가 인증 없이 인터넷에서 직접 접근 가능

---

## 2차 피해 시나리오

- 관리자 로그인 페이지 탐색 후 Brute Force·Credential Stuffing 공격
- 관리자 계정 탈취 시 전체 사용자 데이터·결제 정보 유출
- 관리자 기능으로 악성코드 업로드, 사용자 권한 조작

---

## 해결 및 대응방안

### ① 관리자 서비스를 별도 서버·포트·도메인으로 분리

```
일반 서비스: https://www.service.com         (공인 IP, 인터넷 접근 허용)
관리자 서비스: https://admin.internal.com     (사설 IP, 내부망만 접근 허용)
또는:         https://www.service.com:8443   (별도 포트, 방화벽으로 내부망만 허용)
```

### ② 관리자 페이지 경로를 추측 불가능하게 설정

```
금지: /admin, /manager, /master, /administrator, /management
권고: /c3d1e9a2f8b7/ 등 무작위 경로 사용, 또는 별도 서브도메인
```

### ③ IP 접근 제어 (서버·미들웨어 수준)

```java
// Spring Security: 관리자 경로 IP 제한
@Configuration
public class SecurityConfig extends WebSecurityConfigurerAdapter {
    @Override
    protected void configure(HttpSecurity http) throws Exception {
        http.authorizeRequests()
            .antMatchers("/admin/**")
                .access("hasRole('ADMIN') and hasIpAddress('192.168.10.0/24')")
            .anyRequest().authenticated();
    }
}
```

```apache
# Apache: 관리자 경로 IP 제한
<Location /admin>
    Require ip 192.168.10.0/24
    Require ip 10.0.0.0/8
</Location>
```

### ④ 외부 접속이 불가피한 경우 추가 인증 적용

```java
// 관리자 로그인 시 SMS/이메일 인증 추가 (2FA)
@PostMapping("/admin/login")
public String adminLogin(String userId, String password, HttpSession session) {
    // 1단계: ID/PW 검증
    if (!authService.validate(userId, password)) {
        return "redirect:/admin/login?error";
    }
    // 2단계: OTP 발송 후 추가 검증 페이지로 이동
    otpService.sendOtp(userId);
    session.setAttribute("pendingAdminId", userId);
    return "redirect:/admin/login/otp";
}
```

### ⑤ 관리자 세션을 일반 사용자 세션과 완전 분리

```java
// 관리자용 별도 세션 설정 (application.properties)
// 일반 세션과 쿠키 이름 분리
// server.servlet.session.cookie.name=JSESSIONID   (일반)
// 관리자: 별도 필터에서 ADMIN_SESSION 쿠키로 관리
```

## 보완방안

- 관리자 로그인 시도 로그 기록 (IP, 시각, 성공/실패) — 비정상 접근 이력 모니터링
- 관리자 계정 로그인 시 담당자에게 알림 발송 (이메일·Slack 등)
- 주요 정보를 처리하는 관리자 서비스는 물리적 또는 논리적 망 분리 적용
- 관리자 페이지 URL을 robots.txt Disallow에 등록 금지 — 오히려 경로가 노출됨
