# 3-3. 계정 정보 파악 가능성

> 게시물 작성자, 댓글 작성자, 이벤트 당첨자 등에 계정 정보를 그대로 노출하거나  
> 추측 가능한 관리자 계정을 사용할 경우, 공격자가 이를 기반으로 인증 공격을 시도할 수 있는 취약점.

---

## 근본적인 원인

- 게시물·댓글 등에 로그인 ID(계정명)를 그대로 노출
- 관리자 계정으로 `admin`, `manager`, `administrator`, `system` 등 추측 가능한 이름 사용
- 로그인 실패 시 "해당 아이디가 존재하지 않습니다" 등의 메시지로 계정 존재 여부 노출

---

## 2차 피해 시나리오

- 노출된 계정명을 기반으로 Brute Force·Dictionary Attack
- 관리자 계정 식별 후 집중 공격으로 관리자 권한 탈취
- 개인정보(성명·이메일·사번 등 계정명에 포함된 경우) 수집 → 피싱·사회공학 공격

---

## 해결 및 대응방안

### ① 계정명 노출 시 마스킹 처리

가이드라인 예: `abcd**` / `ab***fg` — 계정명 전체 노출 금지, 일부만 마스킹하여 표시

```java
// 계정명 마스킹 유틸리티
public String maskUsername(String username) {
    if (username == null || username.length() <= 2) return "***";
    int visibleLen = Math.max(1, username.length() / 2);
    String visible = username.substring(0, visibleLen);
    String masked  = "*".repeat(username.length() - visibleLen);
    return visible + masked;  // "abcd" → "ab**"
}
```

```java
// 화면 출력 시 마스킹 적용
String display = maskUsername(post.getAuthorId());
model.addAttribute("authorDisplay", display);
```

### ② 화면에는 닉네임(별명) 표시, 계정명(ID) 미노출

```java
// 사용자 테이블에 닉네임 별도 관리
// nickname 컬럼 사용 → 게시판 작성자, 댓글 작성자에 nickname 출력
model.addAttribute("author", post.getAuthorNickname());  // 계정명 대신 닉네임
```

### ③ 관리자 계정 추측 방지

```java
// 관리자 계정 생성 시 추측 불가능한 이름 강제
String[] forbiddenNames = {"admin", "administrator", "manager", "system", "root", "master"};
if (Arrays.asList(forbiddenNames).contains(username.toLowerCase())) {
    throw new BusinessException("사용할 수 없는 계정명입니다.");
}
```

### ④ 로그인 실패 메시지 통일 (계정 존재 여부 미노출)

```java
// 취약: 계정 존재 여부를 알 수 있는 메시지
// "해당 아이디가 존재하지 않습니다."
// "비밀번호가 일치하지 않습니다."

// 안전: 통일된 에러 메시지
if (user == null || !passwordEncoder.matches(password, user.getPassword())) {
    model.addAttribute("error", "아이디 또는 패스워드가 올바르지 않습니다.");
    return "login";
}
```

### ⑤ 불필요한 계정 목록 페이지 제거

```java
// 관리 목적이 아닌 경우 사용자 목록 API 비활성화
// 노출이 필요한 경우 인증·인가 후 최소한의 정보(마스킹된 계정명)만 반환
@PreAuthorize("hasRole('ADMIN')")
@GetMapping("/api/users")
public List<UserDto> getUsers() { ... }
```

---

## 보완방안

- 이벤트 당첨자 등 공개 게시 시 계정명 전체 대신 마스킹 또는 닉네임만 표시
- 가입 시 닉네임·표시명 입력 필드를 필수로 지정하고 계정명과 독립적으로 관리
- 비밀번호 찾기 기능에서도 "해당 계정이 존재하지 않습니다" 노출 금지 — 통일된 안내 메시지 사용
