레인보우 테이블 해시 크랙 · 오프라인 진단기
========================================

offline-rainbow-crack.html 파일을 다운로드한 뒤 인터넷이 없는 PC에서
브라우저로 직접 열면 동작한다. 설치·빌드·서버·외부 라이브러리는 필요하지 않다.
입력한 평문과 해시는 브라우저 메모리에서만 처리하며 네트워크로 전송하지 않는다.

사용법
------
1. "원본값 → 해시 (생성·검증)"에서 평문을 입력해 MD5, NTLM, SHA1,
   SHA256, SHA384, SHA512, CRC32 결과를 확인한다. 비교할 해시를 넣으면
   일치하는 알고리즘을 표시한다. 결과 복사 버튼으로 값을 복사한다.
2. "해시 → 원본값 (사전)"에 raw 16진수 해시를 붙여넣는다. 해시 길이로
   알고리즘 후보를 판별하며, 필요하면 직접 선택한다. 내장 단어와 대소문자,
   숫자·연도·기호 접미사, 리트스피크 변형을 차례로 대조한다. 숫자 PIN
   전수조사를 추가하면 4~6자리 중 선택한 길이까지 더 시도한다.
3. "해시 → 원본값 (브루트포스)"에서 문자셋과 최소·최대 길이를 정한다.
   짧은 길이부터 모든 조합을 순서대로 시도한다. 후보 수와 진행률·속도·
   예상 시간을 확인하고, 필요하면 중단 버튼을 누른다.
4. "여러 해시 일괄 크랙"에서 해시를 한 줄에 하나씩 입력하고 사전 또는
   브루트포스를 선택한다. 해시별 결과가 순차적으로 쌓인다. 중단하면 이미
   처리한 결과는 화면에 남는다.

한계
----
이 도구의 이름과 달리 저장된 레인보우 체인을 읽지 않는다. 후보를 즉석에서
해시해 비교한다. 사전은 실제 유출 데이터가 아니라 공개적으로 알려진 흔한
비밀번호 패턴에서 생성한다. "못 찾음"은 평문이 없다는 증거가 아니다.
지정한 사전·문자셋·길이 밖에 있거나 솔트가 적용됐을 수 있다. raw 해시값
자체만으로 솔트 적용 여부를 판별할 수 없다. bcrypt·argon2·scrypt·
sha256crypt 같은 솔트+저속 해시는 이 방식으로 원천적으로 못 뚫는다.
SHA 계열은 브라우저 Web Crypto가 있어야 사용 가능하다. 해당 기능이 없는
브라우저에서는 MD5·NTLM·CRC32만 계산한다. 브루트포스는 단일 탭에서
순차 실행하고, 후보가 1억 개를 넘으면 실행을 막는다. CRC32는 암호학적
해시가 아닌 체크섬이다.

안전
----
업무 승인 범위에 있는 해시만 분석한다. 찾은 평문을 무단 인증이나 접근에
사용하지 않는다. 해시·평문·결과를 외부 사이트에 올리거나 공유하지 않는다.
이 파일은 값을 전송하지 않지만 브라우저의 클립보드·방문 기록과 운영체제의
임시 저장 정책은 별도로 적용될 수 있다.
