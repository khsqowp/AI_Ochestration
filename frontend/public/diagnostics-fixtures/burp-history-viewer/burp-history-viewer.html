Burp History 뷰어

Burp Suite의 HTTP history XML을 요청 한 줄씩 살펴보고 요청·응답 원문과 경로 목록을 확인한다. 서버로 전송하지 않음, 브라우저 안에서만 파싱 -- 이 HTML 파일 하나로 인터넷 없는 PC에서도 동작한다.

Proxy > HTTP history에서 우클릭 > Save items로 저장한 XML을 선택하거나 여기에 끌어 놓으세요.
