JavaScript 오프라인 분석기
==========================

offline-js-parser.html 파일을 다운로드한 뒤 인터넷이 없는 PC에서 브라우저로
열면 동작한다. 외부 라이브러리와 서버 요청을 사용하지 않으며, 입력한 코드와
결과는 브라우저 메모리에서만 처리한다.

사용법
------
1. JavaScript 코드를 붙여넣거나 파일 열기로 .js/.mjs/.cjs/.txt 파일을 선택한다.
2. 간단 정리 결과와 API 주소, 비밀값 패턴, 주석 후보를 확인한다.
3. 결과 복사 버튼을 사용하거나 화면에서 직접 복사한다.

한계
----
Beautifier는 중괄호·세미콜론을 기준으로 줄을 나누는 간단한 처리다. 구문 트리
기반 포맷터가 아니며 문자열·정규식·템플릿 리터럴의 복잡한 문법을 완전하게
해석하지 않는다. 엔드포인트·비밀값 정규식은 후보를 찾을 뿐 실제 사용 여부나
유효성을 증명하지 않는다. 검색 결과는 코드와 다른 증거로 수동 확인해야 한다.

안전
----
업무 승인 범위에 있는 자료만 분석한다. 민감정보를 포함한 소스 파일을 공유하거나
외부 사이트에 올리지 않는다. 이 도구는 파일을 전송하지 않지만 브라우저/운영체제의
다운로드 기록과 임시 저장 정책은 별도로 적용될 수 있다.
