# 배경 및 목표

Orchestration Lab에 "Trader Q" 에이전트를 추가한다. Bybit 거래소에서 암호화폐를
자동매매하되, 기존 경제팀(Atlas Lead/Scout E)의 LLM 종합 분석을 매매 판단에
결합하는 것이 핵심 차별점이다. 오피스 화면에 에이전트 자체는 이미 배치했고
(id: `trader`, 초록색, 경제팀 옆), 실제 매매 로직은 아직 구현 전이다.

현재 상태: **설계 확정 대기.** 이 문서의 내용을 기준으로 피드백 후 구현 착수.

# 의존관계

- **경제팀(Atlas Lead / Scout E)**: 매일 생성되는 경제 아카이브 종합 문서를 읽어
  "레짐 필터"(강세/약세/리스크오프 판단)로 사용한다.
- **출처 등록/디스커버리 시스템**: 크립토 전용 뉴스 소스(코인데스크 등)를 경제팀
  출처에 추가 등록해야 할 수 있다.
- **Bybit API**: 시세(웹소켓)·주문·잔고 조회용 신규 백엔드 모듈이 필요하다.
  - 모의투자: `api-demo.bybit.com` — 실전과 100% 동일한 API, 테스트코인 $10K 제공,
    주문 내역 7일 보관.
  - 웹소켓 시세 스트림은 API 호출 제한(rate limit)에 포함되지 않는다 — 실시간
    신호 계산에 자유롭게 사용 가능.
- **아카이브/다이제스트 파이프라인**: 일일 매매 리포트를 마크다운으로 저장하고
  n8n으로 Slack 발송 (기존 `digest-to-slack.json` 패턴 재사용, 신규
  `trading-report-to-slack.json` 워크플로 예정).
- **신규 DB 테이블(예정)**: 매매 내역(trades), 포지션(positions), 일일 손익
  (daily P&L), 리스크 상태(연속 손절 횟수, 당일/주간 손실 누적 등).

# 투자 방식

- **자산**: Bybit **현물(Spot)** BTC/ETH만. 레버리지·선물(무기한계약)·알트코인은
  제외. 이유: 선물은 펀딩비(8시간마다 발생)와 청산 리스크가 추가되고, 첫
  자동매매 시스템에는 과도한 리스크. "공격적" 투자 성향은 레버리지가 아니라
  포지션 크기·진입 빈도로 표현한다.
- **자본 운용 단계**:
  1. **모의투자**: 나중에 실제로 투입할 목표 금액을 가정하고 전략 자체를 검증한다
     (가상 잔고이므로 얼마든 키워서 시뮬레이션 가능).
  2. **실전 5만원**: 전략 성과 검증용이 아니라, 코드가 진짜 계좌에서 정상적으로
     주문·체결·잔고 갱신을 하는지 확인하는 **스모크테스트 용도**. 이 금액에서는
     수수료 대비 리스크 캡(0.25%)이 너무 작아 거래 자체가 잘 안 나갈 수 있는데,
     그건 의도된 것 — 실행 코드 검증이 목적이지 수익 검증이 아니다.
  3. **단계적 증액**: 문제없이 몇 주간 안정적으로 돌면 5만 → 10만 → 20만원 순으로
     2배씩 증액. 한 번에 목표 금액까지 점프하지 않는다.
- **입금 방법**: USDT를 TRC20 네트워크로 입금(수수료 저렴). TRX는 별도 매매
  자산이 아니라 입금용 네트워크 개념.

# 전략 — "15분봉 상태전환형" (코어) + 경제팀 오버레이 필터

두 개의 AI 제안(자체 리서치 기반 "센티먼트 게이팅형 평균회귀" vs 외부 AI의
"15분봉 상태전환형")을 비교분석한 결과, **외부 AI 안의 기계적 실행 스펙을
코어로 채택**하고, 그 위에 **경제팀 LLM 종합을 오버레이 거부 필터**로 얹는
병합안으로 확정했다. 이유는 "다른 AI 안이 더 나은 점 / 빠진 것" 절 참고.

## 시장 상태 판단

- **추세돌파 모드** (ADX(14) ≥ 22, 1시간봉 EMA20 > EMA50일 때만 사용)
  - 진입: 15분봉 종가가 최근 20개 봉의 고가를 거래량 증가(직전 20봉 중앙값의
    1.5배 이상)와 함께 돌파
  - 손절: 진입가에서 `1.3 × ATR(14)`
  - 1차 익절: `+1R`에서 절반 청산
  - 잔여 포지션: `1.8 × ATR` 추적손절
  - (숏 가능 거래소 기준 반대 방향 대칭 적용 — 단, 본 계획은 현물이라 숏 제외)
- **평균회귀 모드** (ADX(14) < 18일 때만 사용)
  - 진입 후보: 가격이 VWAP 또는 볼린저밴드 하단에서 크게 이탈 + RSI(3) < 10
  - 실제 진입: 가격이 밴드 안으로 복귀하고 직전 봉 고가를 돌파할 때
  - 손절: 최근 저점 아래 또는 `1.0 × ATR`
  - 익절: VWAP, 볼린저 중심선 또는 `1.2~1.5R`
  - 하락 추세가 강하거나 거래량이 폭발한 구간에서는 비활성화
- **ADX 18~22 구간**: 두 모드 모두 비활성 (애매 구간, 거래 안 함)

## 경제팀 오버레이 필터 (이 프로젝트만의 차별점)

기술적 신호가 조건을 충족해도, 경제팀(Atlas Lead) 최신 종합 문서가 "리스크오프/
약세" 판단이면 롱 진입을 보류한다. 온체인 지표(MVRV, 거래소 유입량 등)도 추가
필터로 검토 가능하나 초기 버전은 비용(유료 데이터) 때문에 보류 — 데이터 소스
절 참고.

## 거래 금지 모드 (신호가 나와도 진입하지 않는 조건)

- 예상 수익이 수수료·스프레드·슬리피지 합계의 3배 미만
- 호가 스프레드가 평상시의 2배 이상
- 데이터 누락 또는 거래소 연결 불안정
- 일일 손실 한도 도달
- 주요 경제지표 발표(FOMC 등) 직전
- ATR이 최근 중앙값의 3배를 초과하는 급변동 구간

> FOMC 일정·연준 금리 등 구체적 수치는 리서치 시점(2026-07) 기준이며, 실제
> 이벤트 필터 구현 시 연준 공식 캘린더로 재확인 필요 (직접 검증 안 된 상태로
> 하드코딩하지 말 것).

# 리스크 관리 규칙 (손실 최소화 — 수익 신호보다 우선)

- 거래 1회 최대 위험: 총자산의 **0.25%**
- 하루 최대 손실: **1%**
- 주간 최대 손실: **3%**
- 동시 전체 위험: 총자산의 **0.75% 이하**
- 연속 3회 손절: **6시간 거래 중단**
- 고점 대비 **6% 손실**: 실거래 중단 후 재검증
- 물타기·손절 확대 금지
- 시장가 주문은 긴급 손절에만 사용
- 손절 주문은 **거래소 서버측 스탑오더**로 등록 (API 장애 시에도 유지되도록)

포지션 사이징: `포지션 수량 = (계좌 잔고 × 거래당 위험률) ÷ |진입가 - 손절가|`

# 보유시간 로직

- 기본: 진입 후 **23시간** 경과 시 청산
- 아래 조건을 **모두** 만족할 때만 최대 **72시간**까지 연장:
  - 미실현 이익 최소 +1R
  - 1시간·4시간 추세가 같은 방향
  - 추적손절이 최소 본전 이상으로 상향
  - 비용 차감 후 예상 추가수익이 양수
  - 모델의 보정된 성공확률 60% 이상
  - 거래량·호가 유동성·모멘텀이 악화되지 않음
  - 다음 보유기간 안에 주요 이벤트 없음
- 보유 연장은 "새로운 매수 결정"으로 취급 — 손실 중인 포지션을 버티기 위한
  연장 금지.

# 거래 실행 흐름

1. 15분봉마다 신호 계산 (ADX/EMA/RSI/ATR/VWAP/볼린저)
2. 경제팀 오버레이 필터 통과 확인
3. 거래 금지 모드 조건 체크
4. 포지션 사이징 계산
5. 주문 실행 (지정가 우선, 손절은 서버측 스탑오더)
6. 체결 확인 → 포지션/리스크 상태 업데이트

# 검증 기준 (백테스트 통과 게이트 — 실제 봇 구현 전 필수)

두 AI 제안의 파라미터(ADX 임계값, ATR 배수, RSI 기간 등)는 전부 **검증되지
않은 가설**이다. 실제 Bybit BTC/ETH 데이터로 워크포워드 백테스트를 먼저 통과
해야 실거래 코드를 만든다.

- 최소 2~3년 데이터, 수수료·실제 호가 스프레드·슬리피지 반영
- 시간순 워크포워드 검증 (상승장/하락장/횡보장 각각 평가)
- 합격 기준 예시:
  - Profit Factor ≥ 1.25
  - 최대낙폭(MDD) ≤ 10%
  - 테스트 구간 300회 이상 거래
  - 비용을 2배 적용해도 기대값이 양수
  - 특정 코인·특정 연도에만 수익이 집중되지 않을 것

# 데이터 소스

## Tier 1 — 우선 사용 (무료/기존 자산)

| 소스 | 용도 | 비용 |
|---|---|---|
| Bybit 웹소켓 | 시세, 호가, 펀딩레이트 | 무료 |
| 기존 경제팀 파이프라인 | 레짐 판단용 종합 분석 | 이미 있음, 추가비용 0 |

## Tier 2/3 — 보류 (소액 단계에서는 비용 대비 효과 낮음)

Glassnode(MVRV/NUPL 등, $79/월), CryptoQuant($199/월), Augmento 센티먼트
($299/월) 등은 조사에서 추천되었으나, 소액 시작 단계에서는 비용이 기대수익을
초과할 수 있어 **전략이 실제로 검증되고 자본이 늘어난 뒤에만 추가 검토**한다.

# 두 AI 제안 비교분석 요약 (판단 근거)

**외부 AI 안이 나은 점**: 현물·레버리지 없이 시작 권장, 구체적 숫자의 리스크
캡, "예상수익 < 비용×3배면 거래 안 함" 필터, 보유시간 로직, 구체적 백테스트
합격 기준. 자체 리서치보다 실행 가능성이 높음.

**자체 리서치(내 안)에서 가져온 것**: 경제팀 LLM 종합을 레짐 필터로 결합하는
아이디어 — 외부 AI 안에는 이 부분이 없었고, 순수 기술적 지표만 쓰면 일반적인
TA 봇과 차별점이 없어짐.

**공통 주의사항**: 리테일 자동매매 봇의 73%가 6개월 내 실패, 크립토 백테스트는
생존편향으로 수익률이 17~400% 부풀려지는 경우가 흔함 — 두 AI가 제시한 구체적
수치(ADX 임계값, 예상 Sharpe/수익률 등) 모두 실제 워크포워드 검증 전까지는
참고치일 뿐 확정된 값이 아님.
